# BARBER HOUSE — Telegram Booking Bot

Telegram-бот для автоматизации онлайн-записи клиентов в барбершоп.

## О проекте

Проект представляет собой систему автоматизированной записи клиентов через Telegram с использованием Google Apps Script и Google Sheets.

## Основные возможности

- Просмотр услуг и цен.
- Просмотр списка мастеров.
- Информация о графике работы.
- Адрес и контактная информация.
- Онлайн-запись клиентов.
- Сбор контактных данных.
- Автоматическое сохранение заявок в Google Sheets.

## Технологии

- JavaScript
- Google Apps Script
- Telegram Bot API
- Google Sheets

## Архитектура

Telegram → Google Apps Script → Google Sheets

Рабочая демонстрационная версия.
